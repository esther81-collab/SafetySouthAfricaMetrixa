# Metrixa

**Safety • Support • Hope**

Metrixa is a personal safety companion Flutter application designed to empower users with safety tips, emergency category subscriptions, emergency contacts, and live location sharing.

## Features

- 🛡️ **Safety Categories**: Home Safety, Dating Safety, Transport, Night Out, Personal Safety, Emergency Preparedness, and Online Safety.
- 🔔 **Category Subscriptions**: Subscribe to safety category updates with bell icons and manage subscriptions in Settings.
- 💾 **Saved Tips**: Save important safety tips for quick access later.
- 🚨 **Emergency Contacts & Location Sharing**: Fast dialing for emergency services and sharing live location via SMS / Google Maps.
- 🌐 **Multi-Language Support**: English, Zulu, and Xhosa.

## Getting Started

1. **Install Dependencies**:
   ```bash
   flutter pub get
   ```

2. **Run Tests**:
   ```bash
   flutter test
   ```

3. **Run Application**:
   ```bash
   flutter run
   ```
